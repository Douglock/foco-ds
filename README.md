## 💡 Visão Geral

O **Foco DS** é uma aplicação concebida para desenvolvedores, criadores e profissionais que precisam proteger sua atenção e maximizar a produtividade diária.

Com uma interface moderna e livre de distrações, o app combina as melhores metodologias de **Deep Work (Trabalho Profundo)**, **Timeblocking** e **Pomodoro adaptativo** para proporcionar ciclos contínuos de alta entrega e recuperação consciente.

---

## ✨ Funcionalidades Planejadas

- [x] **Sessões de Hiperfoco**: Temporizador dinâmico com modos adaptativos de concentração.
- [ ] **Interface Minimalista & Imersiva**: Experiência visual fluida e focada no que realmente importa.
- [ ] **Gestão de Tarefas & Blocos**: Definição rápida de metas da sessão com priorização inteligente.
- [ ] **Tracking de Performance & Streaks**: Histórico diário de foco e métricas de constância.
- [ ] **Modo Não Perturbe & Notas Rápidas**: Anote pensamentos passageiros sem quebrar a linha de raciocínio.
- [ ] **Sons & Feedback Sutil**: Notificações táteis/sonoras suaves ao concluir blocos de trabalho.

## 🚀 Como Começar

### Pré-requisitos
- [Git](https://git-scm.com/) instalado no seu ambiente.
- Navegador moderno ou ambiente Node.js.

### Instalação

1. Clone o repositório:
```bash
git clone https://github.com/Douglock/foco-ds.git
```

2. Acesse a pasta do projeto:
```bash
cd foco-ds
```
